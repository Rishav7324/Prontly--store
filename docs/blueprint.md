# **App Name**: Prontly Store

## Core Features:

- AI Prompt Optimization Tool: An AI-powered tool that allows users to test and refine prompts directly on the product page before purchasing.
- Secure Digital Delivery: Integration with Cloudflare R2 and Firestore to generate time-limited, secure signed URLs for file downloads post-purchase.
- Razorpay Payment Orchestrator: Seamless checkout flow integrating Razorpay for UPI, cards, and automated GST invoice generation.
- Serverless Content Discovery: A high-performance product browsing experience using Next.js 15 ISR and Firestore for instant search and SEO-optimized categories.
- Unified Admin Console: A centralized dashboard for managing inventory, viewing analytics via Firestore, and monitoring storage utilization.
- User Access & Permissions: Robust RBAC system powered by Firebase Auth and Firestore to handle Customer, Editor, and Admin permissions.
- Real-time Order Tracking: Instant updates on order status and transaction history using Firestore's real-time listeners.

## Style Guidelines:

- Primary Color: Deep Slate Indigo (#554ED2) for a professional yet creative digital-first brand identity.
- Background Color: Dark Nightfall (#0F0F13), providing a high-contrast foundation for premium content display.
- Accent Color: Electric Azure (#60A5FA), used for CTAs and critical UI interactions to provide sharp visual feedback.
- Headline Font: 'Poppins' for a precise and contemporary feel. Body Font: 'Inter' for objective clarity. Code snippets utilize 'Source Code Pro'.
- Sleek, monoline Lucide-style icons that match the machinic precision of the 'Inter' typeface.
- Responsive bento-grid layouts for product listings, emphasizing clarity and density without clutter.
- Framer Motion transitions for route changes and micro-interactions on purchase buttons to evoke high performance.
